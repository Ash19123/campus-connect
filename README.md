# Campus Connect — Amrita Vishwa Vidyapeetham

A unified student life platform designed to streamline campus communication, collaboration, and community building.


## Overview

**Campus Connect** is a feature-rich single-page web application built for the students of Amrita Vishwa Vidyapeetham. It brings together everything a student needs — from finding study partners to reporting lost items — in one beautifully designed interface.


##  Features

| Module | Description |
|--------|-------------|
|  **Dashboard** | At-a-glance stats, live clock, greeting |
|  **Student Match** | Find peers by branch, year, and interests |
|  **Campus Chat** | Real-time messaging with anonymous mode |
|  **Events** | Browse and RSVP to campus events |
|  **Study Rooms** | Create/join virtual and physical study groups |
|  **Polls** | Launch and vote on community polls |
|  **Confessions Wall** | Anonymously post thoughts and experiences |
|  **Lost & Found** | Report and track lost/found items |
|  **Notes Sharing** | Upload and download peer notes with points |
|  **Senior Connect** | Connect with seniors for mentorship |
|  **Leaderboard** | Gamified contribution tracking |
|  **Timetable** | Weekly class schedule viewer |

##  Getting Started

Just open `index.html` in any modern browser — no build step required.

```bash
git clone https://github.com/YOUR_USERNAME/campus-connect.git
cd campus-connect
open index.html
```
